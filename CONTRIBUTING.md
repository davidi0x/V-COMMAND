# Contributing

Thanks for helping build V/COMMAND. This project is MIT-licensed, terminal-first and privacy-aware.

1. Open an issue outlining your proposal or bug.
2. Keep PRs focused, with tests.
3. Run `python -m unittest discover -s tests -v` and `vcmd demo`.
4. Be precise about what is *measured*, *estimated* and *not available*.
5. Never add silent telemetry, shell-based execution of untrusted input, or deceptive 'verified' claims.
6. Cross-platform behavior (Windows, macOS, Linux) matters.

Suggested first contributions: adapters for agent session outputs, check profiles for popular languages, signed evidence manifests, price-source adapters, and TUI layout experiments. See `docs/ROADMAP.md`.
